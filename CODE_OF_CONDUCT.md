# Code of Conduct

## The standard

Be respectful. Assume good faith. Critique the work, not the person.

This project reviews security findings, which means people will disagree about
severity, false positives, and whether a rule earns its place. Disagree
technically and specifically. "This rule fires on X, which is a normal pattern,
here is the case" is useful. Dismissiveness is not.

## Not acceptable

Harassment, personal attacks, discriminatory language, sustained disruption, or
publishing someone's private information.

## Security findings

Reporting a vulnerability in good faith is always welcome and will never be
treated as hostile. See [SECURITY.md](SECURITY.md) for how to do it privately.

Do not use a public issue to disclose an unpatched vulnerability in this project
or in any extension it inspects.

## Enforcement

Report conduct issues to the maintainer through
[GitHub Security Advisories](https://github.com/mihhhir08/cupel/security/advisories/new)
if private, or by opening an issue if not. Maintainers may edit, remove, or
reject contributions and comments that violate this document, and may ban
persistent offenders.
